# سامانه ثبت و تأیید آگهی

یک پروژه آموزشی با Python و Flask برای مدیریت درخواست‌های آگهی، با دو نقش کاربری:

1. **درخواست‌کننده (`requester`)**: ثبت آگهی و مشاهده وضعیت درخواست‌های خودش
2. **کارمند سامانه (`staff`)**: بررسی درخواست‌ها و تأیید یا رد آن‌ها

## امکانات

- ثبت‌نام عمومی فقط برای درخواست‌کننده
- ورود و خروج امن با Flask-Login
- ذخیره رمز عبور به‌صورت هش‌شده
- ثبت درخواست همراه با تصویر
- نمایش درخواست‌های هر کاربر فقط برای مالک آن
- پنل کارمند با فیلتر وضعیت
- تأیید یا رد درخواست با ثبت دلیل رد
- صفحه عمومی آگهی‌های منتشرشده
- محافظت فرم‌ها در برابر CSRF
- محدودیت حجم و فرمت تصویر

## اجرای پروژه در ویندوز

ترمینال را در پوشه اصلی پروژه باز کن.

### 1. ساخت محیط مجازی

```powershell
py -m venv .venv
```

### 2. فعال‌سازی محیط مجازی

```powershell
.venv\Scripts\Activate.ps1
```

اگر PowerShell اجازه اجرا نداد، می‌توانی در ترمینال CMD از این دستور استفاده کنی:

```cmd
.venv\Scripts\activate.bat
```

### 3. نصب کتابخانه‌ها

```powershell
python -m pip install -r requirements.txt
```

### 4. ساخت حساب کارمند سامانه

```powershell
python create_staff.py
```

نام کاربری و رمز عبور کارمند را خودت وارد کن. این حساب از ثبت‌نام عمومی ساخته نمی‌شود.

### 5. اجرای برنامه

```powershell
python app.py
```

سپس در مرورگر باز کن:

`http://127.0.0.1:5000`

## اجرای پروژه در لینوکس

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python create_staff.py
python app.py
```

## تست سریع

1. یک حساب عادی از صفحه ثبت‌نام بساز.
2. وارد شو و یک درخواست آگهی ثبت کن.
3. از حساب خارج شو.
4. با حساب کارمندی که ساخته‌ای وارد شو.
5. درخواست را تأیید یا رد کن.
6. دوباره با حساب درخواست‌کننده وارد شو و وضعیت را ببین.
7. صفحه عمومی `/ads` را برای مشاهده آگهی‌های منتشرشده باز کن.

## نکات مهم

- این نسخه برای یادگیری و اجرای محلی آماده شده است؛ قبل از انتشار روی اینترنت باید `SECRET_KEY` را از متغیر محیطی تنظیم کنی، حالت debug را خاموش کنی و تنظیمات سرور و فایل‌های آپلود را بازبینی کنی.
- SQLite برای شروع مناسب است. اگر پروژه بزرگ‌تر شد، می‌توان دیتابیس را به PostgreSQL تغییر داد.
- این پروژه پرداخت آنلاین، ویرایش درخواست پس از ارسال یا تأیید چندمرحله‌ای ندارد؛ می‌توان این موارد را در نسخه بعد اضافه کرد.
